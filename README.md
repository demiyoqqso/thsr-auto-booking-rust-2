# THSR Auto Booking (Rust)

Rust-only THSR booking client. It polls the booking flow, selects the first available train, and continues the booking flow.

## Railway CAPTCHA — same service, robust POST handling

The CAPTCHA web page is served by the **same `thsr-auto-booking-rust` service**. You do **not** need to create another service.

Because Railway containers have no desktop GUI, the CAPTCHA image is embedded directly in a browser page. The user only needs to enter the CAPTCHA manually.

### Railway setup

1. Open the **`thsr-auto-booking-rust-2`** service in Railway.
2. Open **Settings**.
3. Find **Networking**.
4. Click **Generate Domain**. This creates the public URL for this same service.
5. Redeploy the service.
6. Start the booking program.
7. When a CAPTCHA is required, the log will print:

   `CAPTCHA REQUIRED`

   followed by a URL similar to:

   `https://your-service.up.railway.app/captcha/<token>/`

8. Open that URL on your own computer, enter the CAPTCHA, and press **送出**.
9. The Rust process receives the code and continues the booking flow.

### If Railway does not expose the domain automatically

Add one variable in **Variables**:

`THSR_PUBLIC_URL=https://your-service.up.railway.app`

Use the exact domain generated by Railway. Do not create a `captcha-server` service.

### Important

The CAPTCHA is intentionally left for manual entry. This project does not attempt to bypass or automatically solve the CAPTCHA.

## Environment variables

The booking options can be supplied through the existing `THSR_*` variables or CLI arguments. See `src/cli.rs` for the full list.

## Telegram notifications

Set these Railway Variables on the same service:

- `TELEGRAM_BOT_TOKEN` — the token from your Telegram bot
- `TELEGRAM_CHAT_ID` — your Telegram chat ID

The program will send:

1. A message immediately when a CAPTCHA URL is created.
2. A success message containing the PNR code, train time, route, seat, price, and payment deadline.

If either variable is missing, booking continues normally and Telegram notifications are simply skipped.
